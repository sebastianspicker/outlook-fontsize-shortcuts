# Security Policy

This project is maintained on a best-effort basis.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Use GitHub Security Advisories if the repository is hosted on GitHub with security reporting enabled. Otherwise, contact the maintainer privately and include:

- affected macOS version
- affected Outlook version (New or Legacy)
- minimal reproduction steps
- whether Accessibility access was already granted to Hammerspoon
